Whitsundays 2027 — Iceland-inspired interface

Upload index.html, style.css, app.js, data.js to your Whitsundays GitHub Pages repository.
This version retains the existing Whitsundays Google login/backend code and itinerary/budget data.
The illustrated daily highlights are unique to each destination.
IMPORTANT: GitHub Pages public JS/data files are accessible even if the UI is login-gated. Do not store private booking information in data.js.
Google sign-in requires the correct OAuth origin and a working Apps Script deployment.
This is an Iceland-inspired adaptation, not a complete transplant of the Iceland codebase.
